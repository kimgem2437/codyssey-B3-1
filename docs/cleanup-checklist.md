## 정리 순서와 이유

의존 관계가 있는 리소스부터 지운다. 순서가 틀리면 "사용 중" 오류로 삭제되지 않는다.

1. [ ] **EC2 인스턴스 종료(Terminate)** — 상태가 `종료됨`인지 확인. 가장 큰 과금 요인
2. [ ] **EBS 볼륨 삭제 확인** — 볼륨 목록이 비어 있는지 확인 (미사용 볼륨도 과금됨)
3. [ ] **Elastic IP 릴리스** — 할당했다면. 연결되지 않은 EIP도 과금됨
4. [ ] **Key Pair 삭제** — 과금은 없지만 정리
5. [ ] **Security Group 삭제** — 인스턴스가 지워진 뒤에 삭제 가능
6. [ ] **Internet Gateway 분리(Detach) 후 삭제**
7. [ ] **Subnet, Route Table 삭제**
8. [ ] **VPC 삭제**
9. [ ] **Billing 대시보드 확인** — 남은 과금 항목이 없는지 확인
10. [ ] **예산 알림(codyssey-b3-1)** — 필요 없으면 삭제
